1. Apa keuntungan memisahkan header dan footer menjadi file component tersendiri, dibandingkan menuliskannya langsung berulang-ulang di index.php?
Jawaban: Kode menjadi lebih rapi, terstruktur, dan dapat digunakan kembali (reusable) tanpa perlu menulis ulang baris HTML yang sama di banyak file. Jika ada perubahan pada menu navigasi, kita cukup mengubah satu file component saja.

2. Perhatikan halaman-halaman admin (Buku, Kategori, Penulis, Pengguna, Profil) pada Bagian 2 - bagian mana pada halaman-halaman tersebut yang mengalami masalah yang sama seperti header/footer sebelum dipisah?
Jawaban: Pada halaman admin sebelum dipisah seperti profil, elemen <aside> (sidebar) dan <header> (topbar) disalin-tempel secara identik di 14 file berbeda, yang akan menyulitkan pemeliharaan jika terjadi perubahan desain.
